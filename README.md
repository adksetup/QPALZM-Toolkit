# 🛠️ QPALZM Toolkit
> 由 AdkSetup 开发的轻量实用工具集，专注解决日常开发与系统操作中的小问题，全部项目均已发布稳定版本。

---

## 项目列表
| 项目名称 | 简介 | 支持平台 | 状态 |
|---|---|---|---|
| [real-full-installer](https://github.com/AdkSetup/real-full-installer) | 完整安装包制作与静默安装工具 | Windows | ✅ 已发布 |
| [pip-gui](https://github.com/AdkSetup/pip-gui) | 图形化Pip包管理工具，可视化执行安装/卸载/检索（已发布 v0.1） | Windows / macOS / Linux | ✅ 已发布 |
| [qpalzm-web-search](https://github.com/AdkSetup/qpalzm-web-search) | macOS专用网页搜索GUI工具，支持百度、必应检索与自定义网址打开（已发布 v0.1） | macOS | ✅ 已发布 |
| [brew-gui](https://github.com/AdkSetup/brew-gui) | Linux/MacOS专用Homebrew图形管理工具，图形界面管理brew软件包（已发布 v0.1） | macOS | ✅ 已发布 |

## 设计理念
- **极简高效**：只做核心功能，拒绝臃肿复杂的界面，用最简单的方式解决实际问题
- **开箱即用**：所有项目均提供二进制包，无需复杂配置，下载即可运行
- **持续迭代**：根据实际使用场景不断优化功能，修复问题，保持长期维护

---

## 使用说明
1.  **获取工具**：点击项目列表中的链接，进入对应仓库
2.  **下载版本**：在仓库的「Releases」页面，选择对应平台的最新版本二进制包下载
3.  **查看文档**：每个项目的 README.md 中都有详细的使用说明和依赖信息

---

## 注意事项
- Windows 平台工具建议在管理员权限下运行，以确保文件读写等操作正常
- macOS/Linux 平台工具需系统自带基础命令，源码运行需安装对应依赖（Dependencies）
- 所有工具均为个人开发，若遇到问题可在对应仓库提交 Issue
